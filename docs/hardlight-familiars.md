# Hardlight Familiars

The approved kit supplies the eight original silhouettes and palettes: crowned golden bee HQ, cyan wolf Codex, ember phoenix Claude, periwinkle fox Gemini, amethyst cat Cursor, mint technofox Grok, cyan whale DeepSeek and cream/emerald llama Ollama. The copied manifest and source README accompany PNG/JPG avatars and portraits in `public/hardlight/`.

`AgentMascot` renders static concept crops with CSS depth, floating, aura, crystal particles and state emotes. This is **2.5D motion, not rigged 3D or articulated animation**. `familiars.ts` maps actual worker execution to idle/thinking/working/reviewing/completed/failed/offline. HQ represents deterministic coordination and reviewed work awaiting Zero. Provider auth/health, task state and Telegram connectivity remain separate evidence sources. Simulation never animates production work; recorder views are labeled historical.

Click a familiar for its inspector: role, actual provider, requested/observed model, effort, unavailable quota provenance, actual worker evidence and Model Control link. Agent names, skills and provider assignments remain editable in Agent Team. The roster itself retains recognizable provider identity names. Telegram health is read from the Telegram dashboard, not inferred from a mascot.

Mascot Studio is labeled **PREVIEW** and lets you select all eight states independently. Off/Subtle/Cinematic preferences honor OS reduced motion; an IntersectionObserver pauses offscreen animation. PNG/JPG export links are avatar previews only. No bot profile API is invoked or bot photo changed.

Future articulated assets should implement the same state/identity interface with layered SVG, Rive or a real 3D rig. Do not advertise those formats until supplied and verified. The kit's concept-crop provenance and distribution limitations remain documented in its copied README.
